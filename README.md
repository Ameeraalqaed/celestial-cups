# Celestial Cups

Hand-painted soup cups by Celeste. This is the request intake website.

## Setup

1. Run `npm install`
2. Drop your `landing.mp4` video into `public/assets/`
3. Set `NOTION_TOKEN` as an environment variable (in Vercel dashboard → Settings → Environment Variables)

## Dev

```
npm run dev
```

## Deploy

Push to GitHub → connect the repo in Vercel → it deploys automatically.
